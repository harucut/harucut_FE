## 가장 큰 발견 — 안전영역

웹은 `env(safe-area-inset-bottom)` 만 5곳에서 쓰고 **top 은 0곳**이었다. 셸은 실패 화면에만 `insets.top` 을 줬다.

## 소스로 확정한 것들 (고쳤다)

- **Konva 변형 핸들이 0.75px** — Transformer 는 부모 스케일을 보정하지 않는데(`Transformer.js update()`) 스테이지가 0.075 배라 기본 10px 핸들이 화면에서 0.75px 이었다. 스케일로 나눠 24px 로.
- **터치 규칙이 아이콘 버튼을 타원으로** — `pointer:coarse` 가 `min-height:44` 만 주고 `a` 와 `h-[30px]`·`h-6` 버튼에는 `min-width` 를 안 줘 30×44·24×44 세로 타원이 됐다(기록 삭제, 업로드 ✕, PageHeader 뒤로가기).
- **`[class*="bg-white/…"]` 부분일치 !important 매핑** — `hover:bg-white/[0.07]` 까지 상시 덮어 라이트 테마 랜딩 네비가 hover 에 흰 알약+흰 글자. 블록을 걷어내고 실사용 두 곳을 토큰으로.
- **theme-color 가 `#0B0B0C` 고정** — 라이트 테마 브라우저 UI 가 검게. media 분기 + 부트스트랩·테마 적용 시 메타 동기화. 딥다크 고정 무대(랜딩·기능)는 머무는 동안 셸·메타에 '다크' 를 알린다.

  "빈 카드"가 아니라 카메라의 어두운 면으로 읽힌다. 테마와 무관하게 어둡다 — DESIGN.md 「테마 정책」에

- **프리뷰 위에는 둘만.** 카메라 꺼짐 안내와 카운트다운(숫자 + 남은 시간 링). "n번째 컷" 같은 라벨은 없다.
  타이머 칩과 시작 버튼은 얼굴 위에서 아래 띠로 내려갔다.
- **아래 가운데 자리 하나**가 카메라 켜기 → 촬영 시작 → 셔터로 바뀐다. 시작 전에 회색으로 죽어 있던

## 4차 — 카운트다운을 카메라 밖으로

3차에서 넣은 카운트다운은 얼굴 위에 **링과 숫자 둘 다** 얹혀 있었다. 셋을 각각 따져 보고
(카메라 관습·물리적 가독성·이 제품의 디자인 규약) 링을 지웠다. 셋 다 같은 답이었다.

- **링과 숫자는 같은 값을 두 번 그린 것**이라 링을 지워도 잃는 정보가 없다. 링만 가진 것은
  초 사이의 연속감인데 `motion-safe:` 라 모션을 끈 기기에서는 그것마저 사라진다.
- **링은 초를 말하지 못한다.** 3초와 8초의 링이 똑같이 생겼다. 사용자는 초로 고르고 옆에서
  "삼, 이, 일" 을 소리내어 센다.
- **3px 헤어라인은 실물 0.5mm** 다. 팔 길이 60cm 에서 시각 3분각으로 시력 역치 근처다.
- **끝점이 안 맞았다.** 남은 초가 1일 때 셔터가 터지는데 호는 `1/간격` 만큼 남아 있었다 —
  3초에서는 원의 3분의 1이 남은 채로 찍혔다. 비율 표시가 자기 문법을 어긴다.
- **초록이 둘이었다.** 위 8컷 게이지가 이미 초록 진행 표시인데 링도 같은 토큰을 썼다.
  게이지는 차오르고 링은 빠져서, 같은 색이 반대 방향으로 다른 축을 셌다.

그리고 **숫자를 프리뷰 밖 아래 띠로 내렸다**(간격을 고르던 칩 자리 = 그 간격을 세는 자리).
밖으로 나오니 세 가지가 한꺼번에 풀린다.

- 얼굴을 안 가린다. 링 96px 은 세로 4컷 프리뷰 높이의 **38%** 였다(361×255).
- 대비가 보장된다. 무대 배경(#0B0B0C) 위라 뒤에 뭐가 찍히든 읽힌다. 얼굴 위에서는 밝은 하늘
  앞에서 **1.4:1** 까지 떨어졌다.
- 그 대비를 벌려고 얼굴을 덮던 **스크림(검정 30%)이 통째로 사라졌다.** 포즈를 잡는 동안
  얼굴이 가장 밝다 — 「사진이 제일 밝다」를 더 세게 지킨다.

빈 자리는 초록을 다시 쓰지 않고 메웠다 — 숫자가 바뀔 때 160ms 안착(`.hc-count-tick`), 찍히는
순간 무채색 전면 플래시(`.hc-capture-flash`, 기본 opacity 0 이라 모션을 끈 기기에서 흰 화면이
남지 않는다). 보조기술에는 매초가 아니라 컷마다 한 번 알린다 — 매초 읽으면 TTS 지연 때문에
3초 간격에서 "일" 이 셔터 뒤에 읽힌다.

**셔터로 직접 찍으면 타이머를 처음부터 다시 센다.** 예전에는 카운트가 이미 최대값일 때(간격의
첫 1초 안에) 누르면 값이 그대로라 effect 가 다시 돌지 않아 흐르던 1초가 이어졌다 — 다음 컷의
첫 칸이 짧았다. `ShootingState.cycle` 을 촬영마다 올려 타이머가 반드시 새로 시작한다.

구현 전에 웹 미리보기로 두 안을 나란히 돌려 보고 정했다.
