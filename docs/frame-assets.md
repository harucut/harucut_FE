# 서버 배경·스티커 등록

서버 변경 없이 `POST /api/admin/frames`로 등록한 시스템 프레임을 편집기 소재로 사용한다.
회원의 프레임 목록에서 `isSystem: true`인 항목만 분류한다.

| 제목 | 편집기 표시 |
| --- | --- |
| `[배경] 웨딩/웨딩홀` | 웨딩 분류의 이미지 배경 |
| `[배경] 웨딩/아이보리` | 웨딩 분류의 단색 배경 |
| `[스티커] 여행/비행기` | 여행 분류의 스티커 |
| `[스티커] 하트` | 분류 없는 스티커 |
| `[프레임] [배경] 봄` | 일반 프레임 (소재로 분류하지 않음) |

태그는 전각 괄호, 대소문자와 공백을 정규화한다. `bg`, `background(s)`, `sticker(s)`도 허용한다.
배경은 현재 편집 중인 `frameType`과 일치할 때만 보여 준다.

- 스티커: `previewKey`에 원본 이미지를 등록한다. 프론트는 서명된 `source` 주소를 사용한다.
- 이미지 배경: `background.type = IMAGE`, `background.key`에 배경 원본의 키를 넣는다.
- 단색 배경: `background.type = COLOR`, `background.value`에 `fff8ee` 같은 6자리 HEX를 넣는다.
- 스티커 권장: 투명 PNG, 긴 변 512px 이하, 300KB 이하. 배경은 해당 프레임 비율에 맞춘다.
- 이미지 제한: HTTPS S3 서울 리전의 사용자 `frames`·`components` 경로, PNG/JPEG/WEBP/GIF,
  10MB 및 1,600만 화소 이하. URL 형식 검사와 별도로 S3가 서명 유효성을 확인한다.
- **등록 항목끼리 S3 키를 공유하지 않는다.** 관리자 삭제는 미리보기·배경 파일도 지운다.
  사용자가 소재를 적용하면 내려받아 편집하며 저장 시 자기 경로로 복사한다.
- 비회원은 인증이 필요한 목록 API를 사용하지 않으므로 번들 스티커만 제공한다.
- 회원 촬영 합성을 위해 CLASSIC/WIDE/GRID/POLAROID 기본 시스템 프레임을 각각 등록해야 한다.
  `[배경]`·`[스티커]` 항목은 합성 기준에서 제외한다.

담당자 확인: 운영 등록과 회원 계정으로 실제 저장·합성까지 확인해야 한다. 로컬 목록 테스트만으로
운영 자산의 존재, S3 CORS, 서명 만료, 요금제 저장 한도를 확인할 수는 없다.
