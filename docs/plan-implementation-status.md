# 고도화 구현 진행 상태

- 기준 기획: 「하루컷 제품 고도화 기획서」 R5(2026-10-26). 판정은 [plan-review-r5-verdict-2026-10-26.md](./plan-review-r5-verdict-2026-10-26.md).
- 범위: P0~P5 전체. 사용자 지시는 「설계에 나온 것을 전부 끝까지 하되, 배포는 하지 않고 develop 까지만」이다.
- 백엔드는 하루컷 백엔드 저장소에서 따로 진행한다. fork `harucut/Harucut` 의 develop 대상이다.
- 상태 표기
  - **완료**: develop 에 merge 됐고 자동 검증을 통과했다.
  - **PR**: 올렸지만 아직 merge 하지 않았다.
  - **진행**: 작업 중이다.
  - **대기(BE)**: 백엔드 계약이나 구현이 먼저 필요하다.
  - **대기(사용자)**: 접근 권한이나 사업 결정이 필요하다.
- 「완료」는 develop 기준이다. 운영 배포와 실기기 확인은 따로 적는다.

## 사용자에게 필요한 것

- AWS 읽기 전용 조회 허락: Lambda 설정, S3 CORS·버전 관리, SQS·IAM (D08·D09·D10)
- 운영 DB 스키마 읽기 허락: Flyway 기준선 편입에 필요 (D11)
- 조건부 PUT 을 시험할 테스트 버킷
- PortOne 상점·채널 키, App Store Connect·Play Console 상품: 실결제·스토어 연동에 필요
- 실기기: iPhone·Android·태블릿 부스, 카카오톡 등 인앱 브라우저
- 사업 결정: 보관 기간, 첫 행사 피크 규모, 부스 유휴 종료 시간, 화이트라벨 조건
- 법무: 약관 제8조·개인정보 처리방침의 행사 참가자 문구
- AGPL 결정: 의무 이행, 별도 라이선스, 대체 중 하나
